# First Invention Website

Bare-bones static website for the First Invention founding stage.

## Included

- Seven public-facing pages: home, program, competitions, teaching fellows, start a chapter, advisors, and about/FAQ.
- A secure Supabase-backed Member Hub with individual student and teacher accounts.
- Teacher chapter creation, private chapter codes, and automatic activation when one confirmed teacher and ten confirmed student accounts belong to the same school chapter.
- Teacher, student, and administrator dashboards, including chapter-kit activation notices.
- Searchable directory of 28,724 current NCES public high schools; it is intentionally a search field rather than an unusable national dropdown.
- Founding-stage language that does not claim nonprofit status, active chapters, active competitions, partners, or impact.

## Run locally

Open `index.html` in a browser, or serve this folder with any static-file server.

## Before public launch

1. Finalize the visual identity and replace the text header with approved logo assets.
2. Add a real First Invention domain email.
3. Finalize legal privacy and terms documents.
4. Have a qualified adult/legal reviewer finalize the privacy and terms documents before inviting students to register publicly.
5. Configure a custom domain, Supabase production redirect URL, and branded authentication emails.
6. Add the completed slide decks, videos, quizzes, and resources to the published lesson area.
7. Add a private-school directory and an approved process for schools not yet listed.
